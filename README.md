# 微信公众号 OCR 采集器

自动采集公众号文章、互动数据（阅读/点赞/转发/喜欢）与评论区，存入 SQLite 数据库并保存文章 HTML。

## 工作原理

**"屏幕替身"式采集**：程序用 SendInput 模拟鼠标键盘操作微信窗口，同时用 OCR 识别屏上数据——`rapidocr_onnxruntime` 识别阅读数、评论层级等；**豆包视觉模型** 结构化识别 4 指标、整理评论内容，识别任务全部异步执行不阻塞主流程。

要点：
- **点位驱动**：每个点位是一个屏幕坐标 (x,y)+名称，程序按点位点击/框选/滚动
- **输入锁定**：采集时拦截人工键盘鼠标（ESC 停止），程序注入操作放行
- **评论层级**：AI 判层级不可靠，改用 OCR 绝对判定（名称行 x 偏移 >20px = 二级）；多屏截图自动拼接后交给 AI
- **全自动**：窗口初始化 → 搜一搜 → 文章列表识别 → 逐篇采集/更新/评论，完成自动停止

## 快速开始

```bash
pip install -r backend/requirements.txt   # 后端依赖
cd frontend/next && npm install && cd ../..   # 前端依赖
npm run dev    # 同时启动后端(:8000)+前端(:3000)
```

首次使用前配置三个按钮（未配完整会**报红+感叹号**，悬停看原因）：
- **点位设置**：每个点位都要有效坐标（可手工录入或"捕获"鼠标位置）
- **滚动设置**：滚动距离须大于 0
- **AI 模型**：填 API Key + 模型 ID（未配则"4指标/评论采集"开关自动禁用）

**添加公众号**（任选）：①「新增」手工填名称 ② 采集弹窗粘贴文章链接点「识别」③ 文件导入 csv/xlsx，或拖拽含链接的表格进列表。

**采集**：勾选公众号 → 「采集选中」→ 设置弹窗（窗口分离/时间范围/4指标/阅读数/评论采集）→ 确认。弹窗打开任务栏自动隐藏，日志实时显示每一步，ESC 可随时停止。

**查看**：文章列表页支持日期/标题/数值/公众号多选筛选、列头排序、分页、导出 xlsx；行内可更新指标 / 采集评论 / 下载 HTML。评论页支持作者/内容/点赞/IP/层级筛选与导出。

## 架构

```
前端 Next.js(公众号页/文章页/评论页+点位/滚动/AI/分页组件)
   ▲ fetch / SSE 日志流          ▲ localStorage 配置记忆
后端 FastAPI(routers: accounts/collect/points/scrolls/settings)
   services: tasks采集链路 / computer(win32) / ocr / inputlock / doubao_api
   ▼ SQLite  data/collector.db
Windows 微信客户端(SendInput 模拟 + 屏幕截图 OCR)
```

## 核心机制

- **列表后端化**：三个列表分页/筛选/排序全走后端 SQL；筛选变化 400ms 防抖，后端同参 400ms 去重缓存防重复风暴；导出=筛选后全量
- **配置记忆**：三页设置存入 localStorage（collectConfig/updateConfig/commentConfig），刷新不丢；文章/评论页日期筛选与快捷按钮同样记忆
- **完整性校验**：点位/滚动/AI 任一残缺 → 设置按钮报红 → 三页采集按钮置灰+提示原因
- **输入锁定**：程序注入放行，人工键盘拦截（ESC=停止），鼠标含移动拦截+限流提示
- **评论采集**：展开回复 → 逐屏截图 → 连续 3 屏相同即到底 → 拼接 → 豆包识别+OCR 层级判定 → 写库（comment_id=md5(作者|内容|时间)）
- **日志**：后端 `[async]/[step]/[ok]/[fail]/[warn]` 标记，前端统一颜色（青/橙/绿/红/黄）

## 数据

- `data/collector.db`：accounts / articles / comments / points / scrolls / ai_model / sort_config
- 文章 HTML：`D:/article_data/公众号名/日期_标题/`（含图片）
- 迁移：复制 `data/collector.db` 即可带走所有配置与数据

## 常见问题

- **采集按钮置灰**：点位/滚动/AI 有残缺，悬停感叹号看原因
- **任务栏消失**：采集弹窗开着时是程序隐藏了，关闭即恢复
- **"10万+"**：阅读数自动换算为 100000
- **想中途停**：按 ESC 或点「按 ESC 停止」按钮，程序收尾后停止

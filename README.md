# 微信公众号OCR采集器

通过**鼠标点击 + OCR 识别**操作微信 PC 版，自动采集公众号历史文章并保存为 HTML（含图片）的自动化工具。

- 依赖微信 PC 版：**4.1.11.24**
- 纯标准库 GUI（tkinter），OCR 用 rapidocr_onnxruntime
- 不依赖 tool.exe 等外部工具，直接操作微信界面

---

## 一、环境依赖

| 依赖 | 用途 |
|------|------|
| Python 3.11+ | 运行环境 |
| tkinter（内置） | GUI 界面 |
| rapidocr_onnxruntime 1.4.x | 屏幕 OCR 识别 |
| requests | 抓取文章 HTML |
| Pillow（PIL） | 截图 |

安装：
```bash
pip install rapidocr_onnxruntime requests Pillow
```

## 三、配置文件

### 3.1 config/input.csv（任务列表）

| 列 | 说明 |
|----|------|
| 索引 | 任务序号（只读） |
| url | 公众号任一文章的链接 |
| 公众号名称 | 目录名 / 日志显示 |
| 状态 | pending（待处理）/ null（未填链接）/ done（完成）/ error:原因 |

- 任务区表格可直接编辑（双击单元格修改，操作列删除）
- 底部【新增】加空行（状态 null，填链接后自动转 pending）
- 【重置】把有链接的改为 pending、空链接改为 null

### 3.2 config/points.csv（屏幕点位）

| 列 | 说明 |
|----|------|
| id | 点位编号（只读） |
| 点位名称 | 可双击修改 |
| x / y | 屏幕像素坐标（只能通过【修改】采集） |

点位设置弹窗（控制区【点位设置】按钮）：
- 双击名称列 = 改名
- 点【修改】= 鼠标采集坐标（左键单击预览 / 双击确认取单击值 / 右键暂停恢复）
- 点【删除】= 删除该点
- 【新增】= 底部加空行

### 3.3 点位说明（当前配置）

| id | 名称 | 作用 |
|----|------|------|
| 1 | 微信左上角搜索栏 | 触发搜索面板 |
| 2 | 搜索网络结果 | 打开搜索结果 |
| 3 | 搜一搜窗口搜索按钮 | 输入链接后的搜索 |
| 4 | 作者名称 | 进入文章列表页 |
| 5 | 文章列表左上 | OCR 区域对角点1 |
| 7 | 文章列表右下 | OCR 区域对角点2 + 滚动位置 |
| 8 | 文章右上角3点 | 打开文章操作菜单 |
| 9 | 操作项窗口左上 | "复制链接" OCR 区域对角点1 |
| 10 | 操作项窗口右下 | "复制链接" OCR 区域对角点2 |
| 11 | 窗口分离后点击位置 | 开启窗口分离时，点击点位2后额外点击 |

> 点位5/7、9/10 是区域对角点，自动归一化，顺序无关。
> 点位11 仅在采集控制区【窗口分离】开关开启时生效（需先采集坐标）。

### 3.4 config/ui_state.json（界面记忆）

自动保存：索引范围、时间范围、自定义日期、最大采集数量、滚动距离、卡片高度、窗口分离开关。

## 四、界面说明

布局：**左侧控制区（600）+ 右侧任务区（600）**，窗口 1240×700（小屏自动适配）。

### 左侧控制区
- **控制台（日志）**：下方，运行日志实时显示
- **采集控制**（上方）：
  - 索引范围：起始/结束（默认 0 ~ 总数）
  - 时间范围：全部 / 当天 / 近一周 / 近一个月 / 近一年 / 自定义（起止日期，日历选择）
  - 每公众号最大采集数量：空 = 无限（右侧有【窗口分离】开关）
  - 滚动距离 + 测试滚动：文章列表每次滚动距离（默认 70% 屏高）
  - 卡片高度 + 设置：文章卡片高度（用于去重），设置模式连续点两点取 y 差值
  - 开始按钮 + 点位设置按钮

### 右侧任务区
input 数据表格：索引 | 链接 | 公众号名称 | 状态（双击编辑、操作列删除、底部重置/新增）

## 五、采集流程

### 5.1 点击开始后
1. 校验设置（索引/时间/数量格式）
2. 检查微信窗口（找不到 → 弹窗提示，不开始）
3. 启动 ESC 监听（按 ESC 立即停止）
4. 微信靠左半屏 + main 靠右半屏
5. 任务栏自动隐藏（退出时恢复）

### 5.2 单个任务流程
```
① 聚焦微信窗口，检查左半屏（不在则移动并等0.5秒）
② 点位1（搜索栏）→ 输入1 → 删除 → 点位2（搜索网络结果）
   开启【窗口分离】时：点位2 后额外点击点位11
③ Ctrl+Shift+W
④ 点位1 → 输入1 → 删除 → 点位2（触发新窗口）
   开启【窗口分离】时：点位2 后额外点击点位11
⑤ 新窗口调整左半屏并聚焦
⑥ 点位3（搜索按钮）→ 全选删除 → 剪贴板粘贴任务链接 → 回车 → 等5秒
⑦ 点位4（作者名称）→ 等5秒进入文章列表页
⑧ 文章列表 OCR 循环（见下）
```

### 5.3 文章列表 OCR 循环
```
循环：
  1. OCR 识别点位5/7 区域的卡片（命中时间格式即卡片）
  2. 卡片去重：y 差值 < 卡片高度 → 同一张，保留最上面
  3. 依次点击每个卡片：
     - 点击 → 等5秒文章加载
     - 复制链接（最多3次重试）：
       点位8（3点菜单）→ 等2秒 → OCR找"复制链接" → 清空剪贴板 → 点击
       → 轮询剪贴板（10秒/20次，内容变化且含 mp.weixin.qq.com 即成功）
       → 失败则重试（重新点位8）
     - fetch_article 抓取标题/时间 → 保存 HTML 到 下载/会话/公众号名/标题.html
     - 记录成功数
     - 时间范围检测：文章时间不在范围内 → 退出循环
     - 最大数量检测：达到数量 → 退出循环
     - Ctrl+W 关闭文章 → 等1秒
  4. 全部点完 → 鼠标移到点位7 → 滚动配置距离 → 等1秒 → 回到循环开头
停止条件：OCR 无卡片（列表页异常，标记 error）
```

### 5.4 时间识别规则
- 星期X / 周X / 礼拜X、今天、昨天、前天
- X天前 / X小时前 / X分钟前
- 年月日（2026-08-05，非今年）
- 月日（8月21日 / 08-05，今年）

### 5.5 失败处理
任何一步走不通 → 标记 error（写入 input.csv 状态）→ 直接下一个任务：
- 缺少点位 → `error:缺少点位X`
- OCR 失败 → `error:OCR 失败`
- 无卡片 → `error:未识别到文章卡片`
- 复制链接 3 次失败 → `error:复制链接失败(3次)`
- 抓取失败 → `error:抓取文章失败`

## 八、其他功能

- **任务栏**：打开 main 自动隐藏任务栏（全屏操作），正常退出/异常退出自动恢复；强杀进程后需手动恢复
- **文章保存**：保存完整 HTML（图片为外链引用），标题清洗（斜杠/点等特殊字符 → `_`）
- **滚动测试**：人工打开列表页后点【测试滚动】，按配置值滚动验证距离
- **卡片高度设置**：点【设置】→ 连续点两个点（y 差值 = 高度）→ 双击确认 / 右键暂停恢复 / 不满意继续点下一对

## 十、注意事项

1. 采集前请保持微信已登录、处于正常界面
2. 程序运行期间任务栏隐藏，退出自动恢复（勿用任务管理器强杀，否则需手动恢复任务栏）
3. 复制链接依赖剪贴板，请勿在采集时手动使用剪贴板
4. 微信版本变化可能导致点位偏移，需重新采集点位
5. 采集速度受微信响应影响，属正常现象

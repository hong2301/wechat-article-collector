# 微信公众号OCR采集器

自动操作微信 Windows 版，**批量采集公众号文章、互动数据（阅读/点赞/转发/留言）和评论区**。支持自定义时间范围、原创/IP属地识别，结果输出为 CSV + 完整 HTML。

> 依赖微信 Windows 版 **4.1.12.55**，全自动运行（鼠标 + OCR + AI 视觉）。非技术用户可直接用 Release 里的 exe 免安装版。

---

## 快速开始

**方法一（exe 免安装版，推荐）：**
1. 下载 Release 的 zip 包，解压后双击 `微信公众号OCR采集器.exe`
2. 配置 `config\input.csv`：把"url"列换成要采集的公众号的**任一文章链接**
3. 配置点位：程序左下【点位设置】→ 逐个【修改】采集坐标（首次必须做）→【预览】红点验证
4. 填豆包 API Key（评论识别用，火山方舟）
5. 登录微信保持前台 → 点【开始】→ 全程自动

**方法二（源码运行）：**
```bash
pip install rapidocr_onnxruntime requests Pillow
python main.py
```

## 效果

### 采集速度（实测，受微信响应/网络影响）

| 指标 | 速度 |
|------|------|
| **文章采集** | **4~6 秒/篇**（实测 241 篇：平均 5.5 秒，中位数 4 秒） |
| **评论采集** | **约 1 分钟 10~20 条**（滚动采集 + 自动去重） |


### 采集结果：数据结构

**① `data\collected.csv`（文章记录，14 列）：**

| 列 | 说明 |
|----|------|
| 公众号名称 / 日期 / 标题 / 链接 | 文章基本信息 |
| 阅读 / 点赞 / 转发 / 喜欢 / 评论 | 互动数据 |
| 写入时间 | 采集时刻 |
| 互动截图 / 阅读截图 | 截图文件名 |
| 是否原创 | 原创 / 非原创 |
| IP属地 | 如：中国北京、美国 |

**② `data\comments.csv`（评论记录，14 列）：**

| 列 | 说明 |
|----|------|
| 采集时间 | 每条评论第一次被看到的时间（精确到秒） |
| 文章链接 | 所属文章 |
| 名称 / 地区 / 时间 / 点赞数量 | 评论者信息 |
| 正文 | 评论文本 |
| 层级 | 1 = 一级评论，2 = 二级评论（缩进） |
| 是否置顶 / 是否作者回复 / 是否作者点赞 | 标记 |
| 评论ID | 16 位哈希（内容唯一） |
| 父级评论ID | 二级评论的父级（回复关系） |
| 回复数量 | 该评论被多少二级评论回复 |

**③ `data\下载\`（离线可看）：** 每篇文章保存为**独立文件夹**（按公众号分了目录）：
```
下载/<公众号>/<日期>_<标题>/
    ├── <日期>_<标题>.html   ← 完整文章
    └── images/              ← 图片已下载到本地(横杠路径), 双击HTML即可离线浏览, 无需网络
```
> 微信 PC 4.1.12 新版文章为 JS 懒加载结构(图片仅 data-src)，本工具会把图片下载到本地并自动补全 src，确保离线可正常显示。

**示例：**
```
collected.csv:
2026-08-16 18:33 | 误还即扣99元，共享充电宝不容"冒牌"玩心机 | 阅读3593 | 赞61 | 原创 | 中国北京

comments.csv:
2026-08-17 02:03:06 | 文章链接 | 白羊座 | 宁夏 | 7月13日 | 1 | 看了那么多预测冠军的评论… | 2 | fdd30810de23bff7 | 3d051df693b70021 | 0
```

## 界面与配置

### 时间设置（可调节流程节奏）
左下「时间设置」弹窗可配置 17 个主要时间点（两列多行，数字选择器）：
微信就位 / 点击搜索后 / 搜索后等列表 / 作者检测超时 / 点击文章后等待 / 复制链接缓冲 / 文章列表滚动后 / 关闭文章后 / 评论加载 / 阅读数加载等。
支持「恢复默认」，设置自动记忆。

### 界面与配置

**左侧控制区：**

| 配置 | 说明 |
|------|------|
| 索引范围 | 只采 input.csv 指定范围的任务 |
| 时间范围 | 全部 / 当天 / 近一周 / 近一月 / 近一年 / 自定义（默认近 3 天） |
| 每公众号最大文章采集数量 | 空 = 无限 |
| 采集 4 指标 / 采集阅读数 | 点赞/转发/喜欢/留言、阅读数截图 |
| 一级评论采集数量 | 空 = 无限；0 = 不采；>0 = 采 N 条 |
| 每级二级评论采集数量 | 空 = 无限展开；0 = 不展开；>0 = 每条一级下最多 N 条 |
| 滚动距离 / 评论区滚动 | 可【测试滚动】验证 |
| 豆包 API Key | 评论识别（火山方舟 doubao-seed-2-0-mini） |

**右侧任务区：** input.csv 表格（双击编辑 / 删除 / 重置 / 新增）。

**点位设置（23 个点）：** 首次使用需逐个【修改】采集坐标，用【预览】红点验证位置。点位含义见 `config\points.csv` 或程序内点位设置面板的名称列。

## 注意事项

1. 采集前保持微信已登录、正常界面
2. 运行期间任务栏隐藏，退出自动恢复（勿强杀进程）
3. 采集时请勿手动使用剪贴板
4. 微信升级后点位可能偏移，需重新校准
5. 评论采集依赖豆包 API 额度，无额度会明确提示并自动停止
6. ESC 随时停止；单任务失败自动跳过并标记原因

# 微信公众号 OCR 采集器

把"手动刷公众号 + 记数据"变成"一键自动采集"：程序帮你模拟操作微信，自动拉取公众号文章、阅读/点赞等互动数据、评论区内容，并以结构化数据和网页快照的形式保存下来，随时浏览、导出。

---



## 一、它能做什么

程序打开就是公众号管理页：

![首页](docs/screenshots/home.png)

一份简短的能力清单：

- **公众号管理**：新增公众号（粘贴文章链接自动识别，或直接填名称 + biz）、Excel/CSV 批量导入、拖拽排序、批量删除、一键导出
- **自动采集**：勾选公众号点「采集」，程序自动打开微信 → 搜一搜 → 进入公众号 → 逐篇采集，全程无需你动手
- **互动数据识别**：每篇文章的阅读数、点赞、转发、喜欢数自动从页面提取（"10万+"也能自动换算）
- **评论采集**：文章评论区自动展开，抓取多级回复、点赞数、IP 属地、作者回复等
- **网页快照**：每篇文章的完整 HTML（含图片）自动存档到本地，离线可看
- **数据导出**：公众号 / 文章 / 评论一键导出 Excel

## 二、快速开始

程序右上角有一个 **⚡ 快速开始** 按钮，第一次使用**直接点它就行**，无需任何手动配置。

点下后程序自动跑完整个准备流程：

1. **自动识别坐标点位**——告诉程序微信界面上每个按钮在哪（搜索框、菜单、评论区…），识别过程会锁定键鼠，请勿操作
2. **自动获取滚动距离**——文章列表 / 评论区滚动用
3. **检查公众号**——没有公众号会自动导入内置测试号，保证立刻有内容可看
4. **自动采集演示**——跑到今天的文章，让你马上看到效果

全程彩色日志实时显示进度，任何一步想停按 **ESC** 即可。**流程跑完即所有参数就绪**，页面底部红点消失，可以直接开始采集。

> **偶发情况**：极少数机器点位没被自动识别全（红点仍在），这时才需要点开底部的**「点位设置」/「滚动设置」**两个按钮，按提示把缺项补上，保存即可。
>
> **AI 模型（可选）**：只有采集"4 指标 / 评论"内容时才需要配置；不采这些就直接用，不用填 Key。

---

## 三、效率怎么样

- **全自动无人值守**：识别、点击、滚动、翻页全部自动化，勾选后放手即可
- **双引擎识别**：本地 OCR + AI 视觉模型配合，互动指标与评论内容识别又快又准
- **评论自动递归展开**：一级评论、二级回复层层展开并整理，不遗漏"等回复"的隐藏内容
- **并行后台任务**：HTML 快照存档、元信息抓取等放在后台线程，不阻塞主采集流程

---

## 四、输出内容是什么样的

采集结果存成两大部分：

**① 结构化数据**（存数据库，界面里直接看）

- 公众号：名称 / biz / 文章数
- 文章：标题、发布时间、阅读数、点赞、转发、喜欢、评论数、IP 属地、原创标识
- 评论：作者、内容、层级、点赞数、IP 属地、是否作者回复 / 置顶

**② 文件存档**（程序目录下的 `data` 文件夹）

- `data/collector.db` —— 全部数据（sqlite 格式，拷走即完成迁移）
- `data/article_data/` —— 每篇文章的 HTML 快照（按公众号分目录，含图片）

## 五、更细致的使用

**采集设置弹窗（首页右上）**

- 时间范围：只采集某日期段（默认全部）
- 4 指标 / 阅读数 / 保存 Html：按需开关
- 评论采集：开关 + 评论条数上限（一级 / 每级二级数量可调）

**文章列表页**

- 默认按发布时间倒序，最新在前
- 日期快捷范围（今天 / 近一周 / 近一月）、关键词、数值区间、公众号、IP 筛选
- 点表头可切换排序
- 单篇：更新设置、下载 HTML、查看评论、删除
- 多选：批量更新 / 下载 / 删除；文件导入

**评论页**

- 多级评论展开查看，支持关键词 / 点赞 / IP / 层级筛选
- 导出 Excel、批量删除

**AI 模型设置（可选）**

- 只有采集「4 指标 / 评论」内容时才需要：填写豆包 API Key 并选模型。
- 不采集这两类数据可以完全不配，采集照样跑。

## 六、注意事项

- **首次准备**：什么也不用设。第一次使用点右上角「⚡ 快速开始」，全部参数自动就绪；偶发没配全才看底部的「点位设置 / 滚动设置」，AI 只在你需要采集 4 指标/评论时才配
- **微信要求**：微信需已登录、留在前台不被遮挡；程序基于 **微信 Windows 4.1.13.12** 校准，微信版本差异可能导致坐标偏移（版本过高/过低时页面会有提示）
- **采集期间**：程序会锁定鼠标键盘防止误触，并隐藏任务栏；请勿操作，想停按 **ESC**
- **数据在哪**：所有数据与快照在程序目录 `data` 文件夹，整个文件夹复制即可迁移/备份
- **升级**：保留 `data` 文件夹，替换程序本体即可，数据不丢

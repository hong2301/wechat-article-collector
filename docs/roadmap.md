# 未来功能方向（Roadmap）

> 当前版本：V4.1.x 已可完整运行。以下为未来规划的功能方向，按实现复杂度排列。

## 一、点位/滚动设置的「自动设置」（规划中，较复杂）

### 目标
消除点位/滚动的人工配置负担：目前每个点位坐标、每条滚动距离都要人工录入/校准，
未来一键自动识别目标要素并写入。

### 交互位置

**点位设置弹窗**：
- 每行操作列新增「**自动设置**」按钮 → 只对该点位做自动识别
- 列表顶部操作栏新增「**自动设置选中**」→ 批量对勾选点位逐项自动识别

**滚动设置弹窗**：
- 同样增加行级「自动设置」与顶部「自动设置选中」
- 自动识别目标滚动区域（文章列表/评论区）并计算滚动距离

### 实现思路

```
人工预设流程(模板)  →  OCR 读屏  →  AI 视觉识别目标  →  自动写入坐标/距离
```

1. **人工预设流程模板**：为每类点位定义一个"取证流程"（如"点击微信左上角搜索框"=
   先点击左上角区域 → 等待 → 截图该区域 → OCR/AI 从截图中识别目标按钮/输入框位置）
2. **OCR 初筛**：利用现有 rapidocr 引擎读屏文本，锁定目标元素文字位置
3. **AI 视觉模型精确定位**：豆包视觉模型从区域截图识别目标组件坐标（如"搜索按钮"、
   "评论区底部"），换算回屏幕坐标
4. **写入与校验**：识别结果写入点位 x/y（滚动距离按区域比例/实测换算），
   再利用现有"完整性校验 + 预览"机制人工复核

### 依赖与前置

- AI 视觉定位的稳定性：需要针对微信各界面训练/调优提示词（提示词模板需按点位收集）
- 屏幕分辨率差异：识别结果需换算到当前显示器比例
- 滚动距离依赖滚动测试（现有「滚动」按钮）辅助校准
- 新用户引导：可与现有"报红 → 一键自动设置"联动（列表报红时引导点自动设置）

### 里程碑拆分

| 阶段 | 内容 |
|---|---|
| M1 | 单点位「自动设置」原型（选 2~3 个典型点位验证识别成功率） |
| M2 | 点位行级按钮接通用 + 批量「自动设置选中」 |
| M3 | 滚动设置自动识别（区域 OCR + 距离换算） |
| M4 | 提示词模板库收敛 + 异常回退（识别失败 → 保底人工） |

## 二、AI 模型「如何申请」帮助提示（规划中，低复杂度）

### 目标
AI 模型设置行左侧加一个「?」按钮，悬停展示豆包 API 的申请指引，新用户无需外部查资料。

### 展示文本（内置）

> **豆包 API 如何申请**：
> 前往**火山引擎（火山方舟）控制台** → 进入**模型广场/模型市场**选择豆包模型（如 Doubao-Seed）→
> 开通服务后创建 **API Key**（形如 `ark-xxx`）→ 将 Key 与本页模型 ID 填入设置即可使用。

### 备注
- 文本先写死在前端；后续可存后端 ai_model 配置表供维护

*维护：优先级与里程碑随实际推进更新；实现前在独立分支原型验证成功率。*
